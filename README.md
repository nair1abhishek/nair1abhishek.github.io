# Abhishek's blog

A GitHub Pages blog with articles, learning notes, and accessible HTML diagrams. GitHub Pages builds the site automatically when changes reach `main`.

## Add an article

Create a Markdown file in `_articles/`, for example `_articles/my-topic.md`:

```yaml
---
title: My article title
description: A short introduction.
date: 2026-11-05
tags: [learning, tools]
audience: Readers who are curious about the topic.
---
```

Write the article below the closing `---` using Markdown. The audience, description, and tags are optional.

## Add a note

Create a file in `_notes/` with the same front matter (audience is optional), followed by your note. Files appear automatically in their archive and on the home page, ordered by date. Use a unique, URL-friendly file name for each entry.

The example files are marked `example: true`; remove or replace them when ready. See [the diagram style guide](https://nair1abhishek.github.io/style-guide/) for HTML diagram examples.
